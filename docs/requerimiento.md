# Requerimientos Funcionales - Gestión de Disponibilidad de Canchas

[RF - 16] El sistema debe permitir registrar la disponibilidad de las canchas.

- El sistema debe permitir identificar a la cancha mediante su ID.
- El sistema debe permitir registrar los horarios de disponibilidad de la cancha.
- El sistema debe permitir registrar períodos en los que la cancha no se encuentre disponible.
- El sistema debe permitir bloquear una cancha por tareas de mantenimiento.

[RF - 17] El sistema debe permitir consultar la disponibilidad de las canchas.

- El sistema debe permitir identificar a la cancha mediante su ID.
- El sistema debe permitir consultar los horarios disponibles de la cancha seleccionada.
- El sistema debe permitir consultar los períodos en los que la cancha se encuentre bloqueada.

[RF - 18] El sistema debe permitir modificar la disponibilidad de las canchas.

- El sistema debe permitir identificar a la cancha mediante su ID.
- El sistema debe permitir modificar los horarios de disponibilidad de la cancha seleccionada.
- El sistema debe permitir modificar los períodos de bloqueo de la cancha seleccionada.
- El sistema debe permitir guardar las modificaciones realizadas.
